# Brand

This directory will define the official OpenBindings identity: positioning,
voice, tone, typography, visual character, and asset usage.

Brand voice is broader than UI microcopy, but it does not override normative
OpenBindings terminology. Product-content guidance belongs under
`experience/`; both layers should share one recognizable personality.

The first stable system is [the OpenBindings identity](identity.md), including
the canonical nested-binding glyph and its usage rules.
